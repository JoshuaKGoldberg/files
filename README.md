# Files

Built PowerPoint files for Josh Goldberg's conference and meetup talks.
Each `<talk>.pptx` is built from its package in [JoshuaKGoldberg/talks](https://github.com/JoshuaKGoldberg/talks), which uploads them here with `pnpm upload`.
Don't edit them here: change the talk in that repository and rebuild it instead.

## Photos

[`photos/`](./photos) holds photos of Josh speaking, shown on [joshuakgoldberg.com/photos](https://www.joshuakgoldberg.com/photos).
Each is named `<date>-<event>-<description>.jpg`, with its location data removed.
Photographers are credited on that page: please credit them if you use one.
